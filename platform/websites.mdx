If you run more than one website or brand, each one can have its own CMO project. Each project operates completely independently — its own Feed, analytics, product documents, writing instructions, and chat history. Activity in one project has no effect on any other.

For inviting collaborators to work on a shared project, see [Manage Team](/platform/team).

### **Adding a New Project**

**To add a new project:**

1. Click the project name in the top left of your CMO dashboard
2. A dropdown shows all your current projects
3. Click **Add Project** at the bottom of the list
4. You will go through a checkout flow to activate the new project

Once activated, the new project goes through the same onboarding as your first one: website scan, strategy documents, SEO audit, and content setup. After that it starts generating its own daily tasks in its own Feed.

### **Switching Between Projects**

You can switch between projects at any time from the project switcher in the top left of the dashboard. Click the project name to open the dropdown and select the project you want.

Projects shared with you by another account also appear in the switcher, marked with a **Shared** badge so you can tell them apart from projects you own.

### **How Projects Stay Independent**

Each project maintains its own:

- **Feed**: daily tasks, SEO and GEO fixes, articles, and social posts generated specifically for that site
- **Analytics**: separate SEO audits, Health scores, backlink data, and AI Readiness Scores
- **Company Panel**: strategy documents, brand voice, competitor analysis, and product information built around that site's content
- **Writing Instructions**: per-platform voice settings that apply only within that project
- **Chat history**: conversations and context are not shared across projects

This means you can run a SaaS product, a content site, and an agency client all from the same Okara account without any crossover.
